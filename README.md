# Telegram Search Bot

Telegram-бот для поиска информации сразу в нескольких источниках: Wikipedia, GitHub и Stack Overflow.

## Возможности

- Поиск статей в Wikipedia.
- Поиск репозиториев на GitHub.
- Поиск вопросов и ответов на Stack Overflow.
- Параллельное выполнение запросов к нескольким источникам.
- Обработка ошибок отдельных провайдеров без остановки всего поиска.
- Ограничение времени выполнения HTTP-запросов.
- Ограничение количества одновременных запросов.
- Форматирование результатов с заголовками, ссылками и дополнительной информацией.
- Тесты для проверки основных компонентов проекта.

- Python версии, совместимой с `pyproject.toml`.
- [uv](https://docs.astral.sh/uv/).
- Telegram Bot Token, полученный через [@BotFather](https://t.me/BotFather).

## Установка

Склонируйте репозиторий:

```bash
git clone <YOUR_REPOSITORY_URL>
cd Telegram_Bot
```

Установите зависимости проекта:

```bash
uv sync
```

## Настройка

Создайте локальный файл конфигурации или переменную среды в соответствии с механизмом настройки, реализованным в файле `bot/config.py`.

Создайте собственный файл `settings.toml`, скопировав содержимое файла `settings.example.toml`.

Откройте `settings.toml` и вставьте свой токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).

Сохраните файл и запустите бота.

**Важно:** не публикуйте свой токен и не добавляйте файл `settings.toml` в GitHub. Убедитесь, что `settings.toml` указан в `.gitignore`. Файл `settings.example.toml` используется как шаблон и не должен содержать настоящих секретов.

## Запуск бота

Запустите бота с помощью команды:

```bash
uv run python -m bot
```

## Как это работает

1. Пользователь отправляет боту поисковый запрос.
2. Служба поиска одновременно отправляет запросы к поддерживаемым провайдерам.
3. Каждый провайдер преобразует свой ответ в общую модель `SearchResult`.
4. Ошибки отдельных провайдеров обрабатываются независимо друг от друга.
5. Форматировщик группирует результаты по источникам и подготавливает удобный для чтения ответ.
6. Бот отправляет отформатированные результаты пользователю.
